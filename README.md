# Touchback

A pixel-art football game for iPad, phones and computers. The whole game is the single file `index.html`. It needs no install and works offline.

**Play:** https://hb-109.github.io/retro_bowl/

On iPad, play in landscape. In Safari, use **Share → Add to Home Screen** to launch it full screen.

## Controls

| Action | Touch | Keyboard and mouse |
|---|---|---|
| Snap | Tap the field | Click or Space |
| Pass | Drag back like a slingshot, then let go | Hold the left button, drag back, release |
| Lob ↔ bullet | Tap a second finger while aiming | Right-click or B while aiming |
| Hand off | Tap the circled running back | H |
| Juke / dive / hesitate | Swipe up or down / forward / back | ↑ ↓ / → / ← |
| Kicks | Tap for power, tap again for direction | Space, Space |
| Timeout | TIMEOUT button | T |
| Pause | II button | Esc |

Difficulty and game speed are in **Settings**: Easy, Medium, Hard, Extreme or Dynamic (the default, which gets harder as you win), and Slow, Normal or Fast plays.

A new franchise starts with a handful of real players and an opening rookie draft. Stand-ins with base stats play every position you haven't filled; your own players wear a yellow star on the field.

Your franchise saves in the browser you play in, in three save slots. **Settings → Back up save** gives you a code to move it to another device.

Touchback is an original game with original art and players; clubs use city names only. It is not affiliated with any professional league or other game publisher.
